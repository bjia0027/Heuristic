# DAG启发式调度器 - 快速使用指南

## 🚀 快速开始

### 推荐配置（高性能模式）⭐

```python
from distcc_external_scheduler.core.dag_heuristic_scheduler_optimized import DAGHeuristicScheduler

# 创建调度器
scheduler = DAGHeuristicScheduler(
    enable_genetic=False,      # 默认禁用，避免20分钟调度时间
    enable_clustering=True,
    enable_batching=True,
    enable_multi_objective=True
)

# 🔧 关键：禁用自动DAG（逐任务调度模式）
scheduler._auto_dag_enabled = False  # 避免重复DAG构建
scheduler._real_dag_enabled = False  # 避免频繁文件I/O

# 使用
for task in tasks:
    decision = scheduler.select_node(task, available_nodes)
    if decision:
        # 执行任务
        execute_task(decision.task, decision.selected_node)
```

**性能**: ⚡ 0.022秒/200任务

## ⚠️ 常见错误

### 错误1: 逐任务调度时启用DAG

```python
# ❌ 错误：导致20分钟调度时间
scheduler = DAGHeuristicScheduler()  # 默认配置
for task in tasks:
    decision = scheduler.select_node(task, nodes)  # 每次尝试构建DAG

# ✅ 正确：显式禁用DAG
scheduler._auto_dag_enabled = False
scheduler._real_dag_enabled = False
for task in tasks:
    decision = scheduler.select_node(task, nodes)  # 快速调度
```

---

### 错误2: 批量调度时不提供DAG

```python
# ❌ 低效：未利用DAG信息
decisions = []
for task in tasks:
    decisions.append(scheduler.select_node(task, nodes))

# ✅ 高效：一次性批量调度
dag, tasks_dict = extract_real_dag(...)
decisions = scheduler.schedule_dag_tasks(dag, tasks_dict, nodes)
```

---

### 错误3: 启用遗传算法但任务很少

```python
# ❌ 浪费：10个任务不需要遗传算法
scheduler = DAGHeuristicScheduler(enable_genetic=True)
# 调度时间：10秒+ （遗传算法开销）

# ✅ 合理：小任务用简单策略
scheduler = DAGHeuristicScheduler(enable_genetic=False)
# 调度时间：<0.01秒
```

## 🐛 故障排除

### 问题1: 调度速度很慢

**症状**: 200个任务需要10分钟以上

**诊断**:
```python
# 检查DAG是否启用
print(f"Auto DAG: {scheduler._auto_dag_enabled}")
print(f"Real DAG: {scheduler._real_dag_enabled}")
print(f"Genetic: {scheduler.enable_genetic}")
```

**解决**:
```python
scheduler._auto_dag_enabled = False
scheduler._real_dag_enabled = False
scheduler.enable_genetic = False
```

---

### 问题2: DAG提取失败

**症状**: 大量"DAG覆盖率不足"警告

**原因**: 
- `compile_commands.json` 路径不对
- 项目root路径配置错误

**解决**:
```python
# 方案1: 禁用真实DAG提取
scheduler._real_dag_enabled = False

# 方案2: 正确配置路径
scheduler.configure_real_dag_extraction(
    project_root="/path/to/project",
    compile_db_path="/path/to/compile_commands.json"
)
```

---

### 问题3: 负载不均衡

**症状**: 某些节点任务过多，其他节点空闲

**诊断**:
```python
# 检查节点状态
for node in nodes:
    print(f"{node.node_id}: load={node.current_load}, "
          f"slots={node.max_slots}, latency={node.network_latency}ms")
```

**解决**:
```python
# 确保节点性能参数正确配置
node.max_slots = 8  # 并发槽位
node.network_latency = 10.0  # 网络延迟(ms)

# 启用性能感知调度
scheduler.enable_hybrid_local_remote = False  # 分布式环境禁用
```

## 📚 API参考

### 核心方法

#### `select_node(task, available_nodes, **kwargs)`

逐任务调度接口

**参数**:
- `task`: CompileTask - 要调度的任务
- `available_nodes`: List[ServerNode] - 可用节点列表
- `kwargs`: 可选参数
  - `dag`: nx.DiGraph - 预构建的DAG（可选）
  - `all_tasks`: Dict[str, CompileTask] - 所有任务字典（可选）

**返回**: SchedulingDecision | None

**示例**:
```python
decision = scheduler.select_node(task, nodes)
if decision:
    print(f"任务 {task.task_id} -> 节点 {decision.selected_node.node_id}")
```

---

#### `schedule_dag_tasks(dag, tasks, nodes)`

批量DAG调度接口

**参数**:
- `dag`: nx.DiGraph - 任务依赖图
- `tasks`: Dict[str, CompileTask] - 任务字典
- `nodes`: List[ServerNode] - 节点列表

**返回**: Dict[str, SchedulingDecision]

**示例**:
```python
dag, tasks_dict = extract_real_dag(project_root, compile_db)
decisions = scheduler.schedule_dag_tasks(dag, tasks_dict, nodes)
```

---

### 配置方法

#### `enable_auto_dependency_sync()`

启用DAG依赖自动同步（将DAG边写回task.dependencies）

#### `disable_auto_dependency_sync()`

禁用DAG依赖自动同步

#### `configure_real_dag_extraction(project_root, compile_db_path)`

配置真实DAG提取路径

## 💡 最佳实践总结

### DO ✅

1. **逐任务调度时禁用DAG**
   ```python
   scheduler._auto_dag_enabled = False
   scheduler._real_dag_enabled = False
   ```

2. **大规模编译时使用批量DAG模式**
   ```python
   dag, tasks = extract_real_dag(...)
   decisions = scheduler.schedule_dag_tasks(dag, tasks, nodes)
   ```

3. **默认禁用遗传算法**（除非>1000个任务）

4. **监控调度时间和Makespan**

5. **根据场景选择策略**

### DON'T ❌

1. **不要在逐任务模式启用DAG推断**（导致严重性能问题）

2. **不要对小任务(<50个)启用遗传算法**（浪费时间）

3. **不要忽略节点性能参数配置**（影响负载均衡）

4. **不要混用逐任务和批量模式**（接口不兼容）
